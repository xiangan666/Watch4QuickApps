# Watch 4 快应用管理 0.1.2

首个公开开发预览版本，面向 Redmi Watch 4。已在 Android 12 / MIUI 手机与实际手表上确认象棋 RPK 可以安装。

- 支持 Root 或 Root 模式 Shizuku 读取本机运动健康配对信息，独立连接 SPP V1 手表并管理快应用。
- 修复 MIUI 旧版蓝牙权限检查造成的误报。
- 安装预检拒绝时保留有效连接；状态码 3 显示设备报告存储空间不足。
- 新增持久详细日志与 UTF-8 文本导出，记录连接阶段、预检状态、分片进度和异常链，自动隐藏密钥与蓝牙地址。
- 提供构建脚本、锁定依赖、源码归档、CI 与 SHA-256 校验文件。

## 下载与升级

安装 `Watch4QuickApps-0.1.2-android-debug.apk`；源码为 `Watch4QuickApps-0.1.2-source.zip`，摘要见 `SHA256SUMS.txt`。原有同签名测试版本可覆盖安装，保留应用数据。首次安装需要 Android 8.0 及以上，读取配对信息需要已存在的 Root 权限，或 Root 模式的 Shizuku。

这是使用调试签名的开发预览版本。其他电脑自行构建的 APK 可能具有不同签名；签名冲突时请先查阅文档，不要直接卸载而丢失本机配置。它不适用于 Watch 4 Active 或 SPP V2 设备；普通 ADB 模式 Shizuku 不能读取运动健康私有库。

## 验证与已知范围

协议测试 17 项、Android 基础测试 19 项通过；APK、测试 APK 与 Lint 构建通过，Lint 保留 3 条非阻断警告。Root 导入、RFCOMM、鉴权、列表和实际象棋安装已验证。Shizuku Root 服务分支尚未在本次手机独立验证，日志导出的系统保存器尚未做跨提供方完整 UI 验收。

源码和安装包不包含研究 APK、用户日志、配对数据库或签名私钥。原作代码尚未指定开放许可证，第三方许可保持不变。
